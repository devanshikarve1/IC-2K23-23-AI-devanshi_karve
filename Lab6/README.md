
# Lab 6 – Deep Learning Fundamentals using PyTorch

## Aim
To understand the basics of PyTorch and implement tensor operations, linear regression and neural networks.

## Topics Covered
1. Tensor Operations
2. Automatic Differentiation
3. Linear Regression using PyTorch
4. Neural Network Basics
5. Model Training
6. Loss Functions
7. Optimizers
8. Model Evaluation

## Learning Outcomes
- Understand PyTorch fundamentals.
- Perform tensor operations.
- Understand automatic differentiation.
- Build basic machine learning models using PyTorch.
