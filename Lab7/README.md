# Lab 7 – Explainable AI, Adversarial AI and Dimensionality Reduction

## Aim
To understand Explainable AI, Adversarial AI and dimensionality reduction techniques through practical implementation.

## Topics Covered

1. Explainable AI using Grad-CAM
2. Adversarial AI using FGSM
3. Principal Component Analysis (PCA)
4. Singular Value Decomposition (SVD)
5. Mini Project

## Learning Outcomes

- Understand Explainable AI techniques.
- Visualize important image features using Grad-CAM.
- Understand adversarial attacks using FGSM.
- Apply PCA and SVD for dimensionality reduction.
- Develop a basic AI application through a mini project.
