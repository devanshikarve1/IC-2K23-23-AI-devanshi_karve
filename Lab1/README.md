# Lab 1 – AI Problem Formulation & Intelligent Problem Solving

## Aim

To understand the basic concepts of Artificial Intelligence and implement simple AI problem-solving techniques.

## Experiments

### 1. AI Environment Setup
File: `EnvironmentSetup.py`

This program checks the Python environment and verifies commonly used AI and data science libraries such as NumPy, Pandas, Matplotlib and Scikit-learn.

### 2. Production System
File: `ProductionSystem.py`

This program demonstrates a simple production rule system using facts, rules and conclusions.

### 3. Water Jug Problem
File: `WaterJugProblem.py`

This program solves the Water Jug Problem using state-space search.

## Programming Language

Python

## Result

The three experiments demonstrate AI environment setup, production-rule reasoning and problem solving using state-space search.
