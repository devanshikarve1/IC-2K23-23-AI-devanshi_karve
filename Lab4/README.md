# Lab 4 – Knowledge Representation & Rule-Based Systems

## Aim

To understand and implement basic knowledge representation techniques, rule-based systems and semantic networks in Artificial Intelligence.

## Experiments

### 1. Knowledge Representation

A simple knowledge base is created using facts and properties of different entities such as Dog, Cat and Bird.

### 2. Rule-Based System

A rule-based system is implemented using IF-THEN type rules to derive conclusions from given facts.

### 3. Semantic Network

A simple semantic network is represented using nodes and relationships between concepts.

## Programming Language

Python

## Concepts Used

- Knowledge Representation
- Facts and Properties
- Production Rules
- IF-THEN Rules
- Semantic Networks

Basic knowledge representation, rule-based reasoning and semantic network concepts were implemented successfully using Python.
